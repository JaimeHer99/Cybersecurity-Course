# Lab 01 - Network Basics

## Objetivo

Comprender cómo mi computadora se comunica con otros sistemas a través de una red.

## Herramientas utilizadas

- Windows
- PowerShell
- Wireshark

## Comandos utilizados

- nslookup github.com
- ping github.com
- tracert github.com

## Protocolos observados

- DNS
- TCP
- TLS
- QUIC

## Lo que observé

Primero se realizó una consulta DNS para conocer la dirección IP del dominio.

Después observé la comunicación entre mi computadora y el servidor.

También identifiqué tráfico relacionado con TCP y tráfico cifrado mediante TLS o QUIC.

## Lo que aprendí

Aprendí que al ingresar un dominio en el navegador, la computadora necesita localizar el servidor correspondiente y después establecer comunicación con él para poder intercambiar información.
